# Contributing

1. Branch from `main`.
2. Run `npm run typecheck && npm run lint && npm test && npm run build` before pushing. CI runs the same checks on every pull request.
3. Add a test with each fix, one that fails without it.
4. Write commit messages following [Conventional Commits](https://www.conventionalcommits.org/), for example `fix: ...` or `docs: ...`.
5. Open a pull request against `main`.
